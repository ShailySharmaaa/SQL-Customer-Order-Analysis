
## 📊 SQL Customer Order Analysis Project

## 📌 Overview
This project analyzes customer purchasing behavior using SQL.

## 🛠️ Tools Used
- MySQL
- SQL

## 📂 Dataset
The dataset contains:
- Customers
- Products
- Orders

## 🔍 Key Analysis Performed
- Customer segmentation (High / Medium / Low buyers)
- Sales analysis by category
- Top selling products
- Repeat customer identification
- Monthly growth analysis
- Cohort analysis
- Order gap analysis

## 📈 Insights
- Electronics generated highest revenue
- Some customers are highly repeat buyers
- Seasonal spikes observed in March & May

## 📁 Files
- `data.sql` → Database creation & data insertion
- `analysis_queries.sql` → All 40 SQL queries

## 🚀 How to Run
1. Run `data.sql`
2. Run `analysis_queries.sql`

## 💡 Skills Demonstrated
- SQL Joins
- Aggregations
- Window Functions
- CTEs
- Business Analysis
